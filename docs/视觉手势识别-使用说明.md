# 视觉手势识别（第一阶段）

## 方案

采用 Google MediaPipe Gesture Recognizer 的开源预训练模型，不采集数据、不重新训练。

- 预训练分类：`Open_Palm / Closed_Fist / Pointing_Up / Thumb_Up / Victory`
- 项目动作映射：`open / grab / point / like / victory`
- `pinch`：基于同一模型输出的 21 个手部关键点，以拇指尖和食指尖的归一化距离判断
- 连续 8 帧一致才确认，手势保持期间只执行一次；空手 8 帧后可再次触发
- 动作库另含 `pinch`（关键点规则识别）和 `middle`（控制台直接执行）；预训练视觉模型没有 `middle` 分类，暂不自动识别
- 默认动作速度为 250
- `Closed_Fist` 映射到合并后的 `grab`，动作参数及前置姿态均以 `gesture_config.py` 为准
- 抓取和捏取采用两阶段动作：先执行各动作在 `pre_angles` 中配置的预姿态，再执行目标弯曲参数；当前间隔为 0 秒，可在 `gesture_config.py` 的 `GRASP_PRE_DELAY` 调整
- 更换灵巧手后，`grab` 和 `pinch` 的最终姿态中第4、5自由度（1-based：食指、拇指弯曲）设为 520，第6自由度（拇指根部旋转）保持为 0；前置姿态以 `gesture_config.py` 当前配置为准

## 文件

- `vision_gesture_control.py`：摄像头识别和灵巧手控制主程序
- `gesture_config.py`：控制台与视觉程序共用的六个实测动作
- `requirements.txt`：Python 依赖
- `models/gesture_recognizer.task`：MediaPipe 官方预训练模型
- `tests/test_vision_gesture_control.py`：映射、捏取规则和防抖测试

## 运行

Windows PowerShell：

```powershell
py -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
```

Linux：

```bash
python3 -m venv .venv
./.venv/bin/python -m pip install -r requirements.txt
```

先只验证识别，不连接灵巧手：

```powershell
python vision_gesture_control.py
```

确认识别稳定后连接灵巧手。Windows 默认 `COM7`，Linux 默认 `/dev/ttyUSB0`：

```powershell
python vision_gesture_control.py --control-hand --speed 250 --force 200
```

程序连接灵巧手后仍默认为未启用动作。点击摄像头窗口并按 `A` 才开始执行；再次按 `A` 停用，`R` 清除当前手势锁存，`Q` 或 `Esc` 退出。真正紧急时直接断开灵巧手电源。

如摄像头不是编号 0：

```powershell
python vision_gesture_control.py --camera 1
```

## 常见错误

`ValueError: Input timestamp must be monotonically increasing` 表示传入 MediaPipe `VIDEO` 模式的相邻帧时间戳相同或倒退。程序现已保证每一帧至少比上一帧增加 1 ms；请使用当前版本的 `vision_gesture_control.py`。
